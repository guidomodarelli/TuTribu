Links en eventos y mensajes
Cómo compartir links de reunión y otros recursos dentro de la tribu.
Fecha: 2026-05-27 Estado: Vigente Alcance: Eventos / Feed
01
Eventos

Al crear o editar un evento, el campo Link de reunión permite pegar un enlace externo para Zoom, Google Meet, Teams u otro proveedor.

  • El link es opcional.
  • Debe comenzar con http:// o https://.
  • Cuando existe, aparece como acción Abrir link y se abre en una pestaña nueva.
02
Mensajes del feed

El editor de mensajes del feed muestra los links dentro del mismo lugar donde se escribe. No hace falta escribir sintaxis especial: se puede pegar un link directo como texto o asociarlo a una palabra seleccionada.

Ejemplo

Si se selecciona google.co y se pega https://google.com, el editor mantiene google.co como texto visible y usa https://google.com como destino. Si luego se agrega la m, texto y destino quedan sincronizados.

  • Al hacer clic en un link dentro del editor, aparece un popover con acciones para editarlo o removerlo.
  • Editar permite cambiar el texto visible y el link asociado.
  • Remover elimina solo el link y conserva el texto.
  • Cuando el texto visible y el destino coinciden, ignorando http:// o https://, las ediciones posteriores actualizan ambos.
  • Cuando no coinciden, las ediciones cambian solo el texto visible hasta que vuelvan a coincidir.
  • Los links visibles en mensajes publicados se abren en una pestaña nueva.
  • Los dominios sin protocolo se guardan con https:// para abrirse de forma segura.
  • Cualquier otra sintaxis de Markdown, incluyendo headings, énfasis o listas, queda como texto normal.
  • El HTML crudo del mensaje se mantiene como texto y no se interpreta como markup.

Los videos embebidos y las encuestas siguen funcionando como recursos independientes del contenido del mensaje.
