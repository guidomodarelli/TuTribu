Imágenes en mensajes del feed
Cómo adjuntar, editar y quitar imágenes en la ronda de mensajes.
Área: FeedEstado: Implementado
01
Crear mensajes con imágenes

Al crear un mensaje en la ronda, el integrante puede adjuntar hasta cuatro imágenes desde el compositor. Cada imagen se sube antes de publicar y queda visible como miniatura para revisar el orden y el contenido.

  • El máximo por mensaje es de cuatro imágenes.
  • Las imágenes que todavía se están subiendo muestran un indicador de carga sobre la miniatura y bloquean la publicación hasta terminar.
  • Después de terminar una subida, el sistema espera unos segundos si el proveedor todavía no confirma que la imagen está lista para adjuntarse.
  • Si una subida falla, se muestra un error seguro y se puede quitar la imagen del compositor.
02
Editar y quitar imágenes

Al editar un mensaje propio, las imágenes actuales aparecen en el compositor. El autor puede conservarlas, quitarlas o agregar nuevas imágenes, siempre dentro del límite de cuatro.

Cuando una imagen se quita de un mensaje editado, deja de mostrarse de inmediato. El sistema intenta borrar el asset remoto en el mismo flujo y registra un evento seguro si el borrado remoto falla.
03
Configuración operativa

El navegador nunca recibe tokens de Cloudflare. La app crea subidas directas desde el servidor con CLOUDFLARE_ACCOUNT_ID, CLOUDFLARE_IMAGES_API_TOKEN, CLOUDFLARE_IMAGES_ACCOUNT_HASH y CLOUDFLARE_IMAGES_DELIVERY_VARIANT.

No escribir secretos reales en documentación, fixtures, capturas ni código fuente. Las variables deben configurarse por entorno.
