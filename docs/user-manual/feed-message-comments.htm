Comentarios en mensajes del feed
Cómo se muestran y cargan las respuestas de una publicación.
Scope: FeedStatus: Active
01
Contador visible

Cada mensaje de la ronda muestra un icono de comentarios junto al total de respuestas publicadas. Ese número representa el total real de comentarios del mensaje, aunque el detalle todavía no se haya abierto.

Cuando existen respuestas, el contador puede mostrar un grupo acotado de avatares con algunos usuarios que comentaron. Ese preview ayuda a reconocer la conversación sin cargar todos los comentarios del mensaje.

Al crear una respuesta, el contador se actualiza en la ronda sin recargar la página.

02
Detalle de respuestas

Al tocar el contador o abrir el mensaje, se muestra el detalle con las respuestas. La ronda evita cargar el contenido de todos los comentarios por adelantado para mantener el feed liviano.

  • El feed carga el total de comentarios por publicación.
  • El feed carga solo un preview limitado de autores de comentarios.
  • Cuando el total es cero, el detalle queda disponible sin mostrar una carga de respuestas innecesaria.
  • Las respuestas completas se cargan recién al abrir el detalle del mensaje.
  • Si la carga falla, la pantalla permite reintentar sin perder una respuesta recién creada.
El contador y el detalle pueden actualizarse en momentos distintos: el contador resume el total, mientras que el detalle muestra el contenido completo cuando hace falta leer o responder.
