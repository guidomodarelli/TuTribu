CONVENTION
Search Indexing
Criterios para exponer rutas publicas a crawlers sin indexar superficies internas.
Scope: Metadata routesStatus: Active
01
Overview

Search crawlers must receive first-class metadata routes from app/robots.ts and app/sitemap.ts. These routes prevent technical paths such as /robots.txt and /sitemap.xml from falling through to the dynamic tribe slug route.

02
Indexable Surface

The sitemap should expose only stable public URLs that are safe to discover without user context. Keep authenticated, invitation, management, and tribe-internal sections out of the sitemap by default.

Robots is a crawler signal, not an authorization layer. Security must continue to live in authentication, authorization, route handlers, and data access rules.
03
Disallowed Routes

The generated robots.txt must disallow:

  • /api/ for backend route handlers.
  • /auth/ for authentication flows.
  • /*/invitar for invitation URLs.
  • Internal tribe sections such as /*/tribu, /*/bienvenida, /*/canales, /*/cursos, /*/eventos, /*/historia, /*/invitaciones, /*/precios, /*/suscripcion, and /*/meritos.
04
Reserved Slugs

Technical metadata route names must stay reserved in src/modules/tribes/domain/value-objects/tribe-slug.ts. Reserve both base names and normalized file-like names, including robots, robots-txt, sitemap, and sitemap-xml.
