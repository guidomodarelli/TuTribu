CONVENTION
Navigation Links
Cómo enlazar entre rutas internas: un único wrapper sobre Next.js Link con prefetch desactivado por defecto.
Scope: UI / NavigationStatus: Active
01
Overview

Todo enlace de navegación interna usa el componente compartido Link de @/components/navigation/link. Es un wrapper delgado sobre el Link de Next.js que deja prefetch en false por defecto y reenvía el resto de las props sin cambios.

02
Goal

Next.js prefetchea los destinos de <Link> por defecto, lo que calienta rutas renderizadas en servidor y agrega carga que el usuario no pidió. Centralizar el comportamiento en un único componente mantiene el prefetch como opt-in en todo el producto y evita repetir prefetch={false} en cada uso.

03
Rules
  • Usá siempre Link de @/components/navigation/link para navegación interna en código de producto (app, components y src).
  • No importes Link desde next/link directamente en código de producto.
  • next/link solo puede importarse dentro de components/navigation/link/index.tsx, el único wrapper permitido.
  • El prefetch es opt-in: pasá prefetch de forma explícita únicamente en la ruta puntual que realmente se beneficie de ser prefetcheada.
El wrapper no aplica estilos ni markup propio: renderiza el Link de Next.js directamente y reenvía className, ref y todas las demás props. Por eso no lleva styles.module.scss.
04
Usage
import { Link } from "@/components/navigation/link";

// Prefetch desactivado por defecto.
<Link href={ROUTES.home}>Volver al inicio</Link>

// Reactivar prefetch solo cuando aporta valor.
<Link href={ROUTES.home} prefetch>Volver al inicio</Link>
05
Notes
  • Funciona con composición asChild de beez-ui (por ejemplo <Button asChild><Link /></Button>) porque reenvía la ref al ancla.
  • El cambio de comportamiento (prefetch por defecto) vive en un solo lugar, así que ajustarlo a futuro no requiere tocar cada uso.
