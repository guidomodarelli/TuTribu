CONVENTION
Agent Stop Quality Gate
Cuándo deben ejecutar validación los hooks de agentes del repositorio.
Scope: .claude / .codexStatus: Active
01
Regla de ejecución

Los hooks Stop de .claude/settings.json y .codex/hooks.json ejecutan node .agents/hooks/stop-quality-gate.js. Ese script revisa primero los archivos modificados con git status --porcelain --untracked-files=all.

Si no hay cambios relevantes para código, tooling o validación, el hook responde {} y no ejecuta typecheck, lint, build ni test.

Si los únicos cambios relevantes pertenecen a tests, el hook ejecuta solo typecheck, lint y test. El comando build queda reservado para cambios de producto, runtime, estilos, base de datos o configuración de tooling.

Los cambios documentales como README.md, AGENTS.md y archivos .htm bajo docs/ no disparan el gate completo por sí solos.
02
Cambios relevantes

El gate selecciona la validación mínima suficiente según los archivos modificados. Debe ejecutar el gate completo cuando al menos un archivo modificado pueda afectar comportamiento de producto, runtime, estilos, base de datos o configuración de validación.

  • Code: .ts, .tsx, .js, .jsx, .mjs, .cjs, .mts, .cts.
  • Styles and data changes with runtime impact: .scss, .css, .sql.
  • Validation and package config: package.json, lockfiles, tsconfig, eslint, jest, next, playwright, postcss, and components.json.
  • Agent validation config: .agents/hooks/stop-quality-gate.js, .codex/hooks.json, and .claude/settings.json.
Si Git status no puede leerse de forma confiable, el hook usa el fallback seguro y ejecuta el gate completo.
03
Validación esperada

Cuando se modifica el script del hook, validar como mínimo node --check .agents/hooks/stop-quality-gate.js, parseo JSON de .codex/hooks.json y .claude/settings.json, el test enfocado de tooling, pnpm run lint y pnpm run typecheck.

Para cambios documentales, se puede validar el comportamiento real con un worktree temporal que tenga solo archivos .htm bajo docs/ o archivos Markdown de control del repositorio, y comprobar que el hook responda {}.
