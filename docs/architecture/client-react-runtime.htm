ARCHITECTURE
Runtime de React en el navegador
Los componentes cliente corren sobre TanStack Redact; el servidor sigue en React.
Scope: Frontend runtimeStatus: Active
01
Decision

TuTribu usa TanStack Redact (@tanstack/redact) como runtime de React en el navegador para reducir el JavaScript que descarga cada pagina. La integracion es withRedact de @tanstack/redact/next, que envuelve la configuracion exportada por next.config.ts.

El codigo de producto no cambia: sigue importando de react y react-dom. withRedact redirige esos imports solo en el bundle del navegador, tanto en Turbopack (reglas con condicion browser) como en webpack (cuando isServer es falso).

Lo que queda en React: el render en servidor, los Server Components, Flight, el cache y el transporte de Server Actions. Redact hidrata el HTML y ejecuta los componentes cliente.
02
Diferencias que hay que tener en cuenta
  • Redact renderiza en forma sincronica: no hay time slicing ni renders interrumpibles. useTransition y useDeferredValue conservan el contenido confirmado y el estado pendiente, pero no bajan la prioridad del trabajo.
  • <Profiler> no ejecuta su callback, cacheSignal devuelve null y unstable_useCacheRefresh no hace nada en el cliente.
  • Los metodos de ciclo de vida legacy de clases no se ejecutan.
  • <Activity> conserva el DOM y el estado ocultos, pero desconecta sus efectos y refs.

La guia completa esta en https://tanstack.com/redact/latest/docs/compatibility.

03
Versiones y alcance
  • withRedact valida la version de Next.js al cargar la configuracion y falla con un error si no esta soportada (en 0.2.0: 15.5 y 16.0 a 16.4). Antes de subir Next.js, subir Redact a una version que la soporte.
  • @tanstack/redact figura en minimumReleaseAgeExclude de pnpm-workspace.yaml: el paquete publica versiones seguido y la integracion con Next.js llega primero en las versiones nuevas, asi que se instala sin esperar las 24 horas de minimumReleaseAge.
  • Los tests de Vitest siguen ejecutando React: Redact solo cambia el bundle que genera Next.js. La verificacion de Redact es pnpm run build y la prueba de la app en https://dev.tutribu.app.
  • Para volver a React en el navegador alcanza con exportar nextConfig sin withRedact.
